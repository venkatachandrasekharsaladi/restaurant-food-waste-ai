AGENT 01 · PREDICTION

Demand Forecasting Agent

Predicts expected meal orders from historical demand and contextual restaurant features.

INPUTS

Meal and centre IDs, week, price, cuisine, centre type, promotion flags and operating area.

PROCESS

Trains and compares regression models using a chronological train/validation split; CatBoost is selected.

OUTPUT

Non-negative predicted order quantity for each validation record.

WHY IT MATTERS

Provides a demand estimate to support preparation decisions instead of relying only on intuition.

Validation: MAE 80.42 · RMSE 165.70 · WAPE 32.42%.

RESPONSIBLE INTERPRETATION

What this prototype does — and doesn't — claim.

✓
Demand prediction

Forecasts order demand using the selected CatBoost model and a chronological validation split.

✓
Preparation recommendation

Calculates target preparation using a configurable safety buffer and available stock.

!
Inventory is simulated

Usable stock in the integrated demonstration results is randomly generated, not sourced from a live inventory system.

!
Potential surplus is not measured waste

The source dataset contains order demand, not actual discarded-food measurements. Surplus/shortfall are estimated operational signals.
